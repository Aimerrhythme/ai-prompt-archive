# AI Prompt Archive

个人学习归档：从 X 收集热门 AI 图/视频生成 prompt。真人与二次元均可。

本仓库只做摘录和索引，供自己回看、对照。非商业。

## 工作日自动化

每个工作日自动跑一轮：

1. 从 X 挑选热门、且带有可复用生成 prompt 的图或视频帖。
2. 按 [条目约定](docs/entry-convention.md) 写入 `entries/YYYY-MM-DD/<post-id>.md`。
3. 图片存入 `media/images/`。视频不入库，只保留原帖链接，并保存一张截图到 `media/video-stills/`。
4. 触及内容政策、或无法确认时，跳过，不写占位条目。
5. 当天没有合格帖子时，不新增条目。

prompt 原文保持原样，不润色、不补写。

## 媒体

- **图片**：保存文件，在条目里写相对路径。
- **视频**：不保存视频文件。条目只留原帖链接，另附一张截图。

## 署名

每条必须保留原帖链接和作者。prompt 归原作者；本仓库不声称原创。

## 内容政策

不收录涉及未成年人的性内容。年龄或尺度判断不准时，直接跳过。

## 声明

个人学习归档，非商业使用。引用或再传播时回到原帖，并遵守原作者与平台条款。

## 目录

```text
entries/YYYY-MM-DD/<post-id>.md   单条归档
media/images/                     图片
media/video-stills/               视频截图
docs/entry-convention.md          字段与模板
```
