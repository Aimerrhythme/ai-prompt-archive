# 条目约定

一条帖子一个文件：`entries/YYYY-MM-DD/<post-id>.md`。  
`<post-id>` 用原帖 ID。同一天可以有多条。没有合格帖子时，不为这一天建目录。

## 模板

```markdown
# <简短标题>

- 原帖链接：
- 作者：
- 时间：
- 互动摘要：
- 模型/工具：
- 标签：真人 | 二次元 | 其它
- 媒体路径：
- 入库日期：YYYY-MM-DD

## prompt 原文

（原样摘录，不改写）
```

## 字段

| 字段 | 怎么写 |
| --- | --- |
| 原帖链接 | X 帖子的完整 URL。视频条目靠这个链接回看，仓库里不放视频文件。 |
| 作者 | 显示名和 `@handle`。 |
| 时间 | 原帖发布时间，保留时区。 |
| 互动摘要 | 采集当时的点赞、转发、回复等数字，注明是采集时的快照。 |
| prompt 原文 | 帖子里的 prompt 原样粘贴。不要翻译、不要润色、不要补全。 |
| 模型/工具 | 如 Midjourney、Flux、可灵、即梦。帖子没写就填「未注明」。 |
| 标签 | `真人`、`二次元`、`其它` 三选一。 |
| 媒体路径 | 图片：`media/images/...`。视频：截图 `media/video-stills/...`，并注明视频仅保留原帖链接。多文件逐条列出。 |
| 入库日期 | 写入本仓库的日期，`YYYY-MM-DD`。 |

## 媒体

- 图片放在 `media/images/`，一条可以多图。
- 视频不提交视频文件。原片只通过「原帖链接」访问；截图放在 `media/video-stills/`。

## 跳过

涉及未成年人的性内容不收录。看不准年龄或尺度时跳过，不留占位条目。
